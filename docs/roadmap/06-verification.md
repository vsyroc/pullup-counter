# Эпик 6. Проверить полный сценарий и описать запуск

## Приёмочные сценарии

| Сценарий | Ожидаемый результат |
| --- | --- |
| Сверить 30 строк программы. Пройти первый `/start` в 20:00, выбрав неделю 9, день 5 и UTC+5 | Бот сразу показывает цели 12, 8, 7, 7, 6. История до регистрации пуста, завтра — день 6. |
| Отправить `6 5 -1 4`, исправить ошибку. Отдельно проверить разницу с целью в 4 и в 5 повторений | Ошибка указывает на третью позицию, до исправления прогресс и таймер прежние. Разница 4 допустима. Все отклонения больше 4 показаны в одной сводке. Подтверждение сохраняет весь ввод один раз. |
| Закончить пятую позицию нулём, затем записать дополнительный подход | Ноль закрывает позицию как пропуск. При четырёх выполненных подходах итог «4 из 5». Дополнительный подход увеличивает общую сумму, таймер выключен. |
| Исправить запись кнопкой и правкой сообщения. Вставить подход задним числом | Порядок определяется временем выполнения. Сводка включает новые отклонения у сдвинутых подходов. При исправлении с пяти позиций до четырёх таймер стартует с сохранения правки. После старта следующей тренировки прежняя зафиксирована. |
| Отправить первый подход в 23:55, подтвердить в 00:05 | Дата тренировки определяется исходным сообщением. В 02:05 приходит тихое напоминание. Если ввод ждёт подтверждения до 11:00, утреннее сообщение сначала предлагает решить его судьбу. |
| Оставить вчерашнюю тренировку открытой к утру | До доставки плана новые числа продолжают вчерашний день. После доставки число без выбора начинает сегодняшний. Кнопка «Доделать вчера» сохраняет прежние цели. После завершения приходит тихий план на сегодня. |
| Закрыть вчерашний план после полуночи. Отдельно начать новый день в 09:30 при закрытом накануне плане | В первом случае числа до утренней доставки идут в дополнительные за вчера, доступна кнопка «Начать сегодня». Во втором план в 11:00 показывает «1 из 5», напоминание остаётся на 11:30. |
| Переключить обычную тренировку в отдых и вернуться к плану с двумя подходами в 18:00 | В режиме отдыха сохранены значения, напоминания выключены. Возврат показывает распределение до подтверждения, затем напоминания назначены на 20:00 и 22:00. Отдых заканчивается в полночь. Кнопка отдыха с прошлой даты показывает актуальный план. |
| Закончить седьмой день недели 9, пропустить два дня, выбрать неделю 10 до первого подхода или после него | Два пропуска остаются в отдельном повторе недели 9. До первого подхода новая неделя начинается сегодня, после него — со следующей местной даты. Вчерашнюю открытую тренировку разрешают первой. |
| Нажать «Пауза» при трёх подходах и прислать число с большим отклонением через две недели | Календарь и рассылки приостановлены. Одно подтверждение возобновляет программу и сохраняет число. В `/history` под тем же днём программы две отдельные строки с датами и результатами. |
| Записать подходы в 11:30 и 13:20. Проверить расписание с управляемыми часами | Срок 13:30 отменён. Без новых записей приходят два напоминания — в 15:20 и 17:20. Для отдельного дня без подходов проверить тихий план в 11:00 и обычное «Пора начать» в 15:00. |
| Сменить UTC-смещение и перезапустить бота с открытым днём | Дата старта сохранена. В `/settings` местное время и ближайшая отправка используют новое смещение. При переходе через 15:00 актуальное «Пора начать» приходит ровно один раз. |
| Восстановить работу после пропущенных отправок | План и «Пора начать» объединяются в одно обычное сообщение. Если пропущены оба напоминания о подходе, первое приходит сразу, второе через два часа. Если первое уже доставлено, просроченное второе пропускается. |
| Два участника одной группы отправляют `/set`. Один вызывает `/plan`, другой — `/history` | У каждого свой дневник. Группа видит краткий ответ, подробности уходят автору лично. Обычные числа в группе игнорируются. Повторная доставка команды сохраняет результат один раз. |
| Отправить групповой `/set` до регистрации. Затем проверить недоступность лички у настроенного пользователя | При первом запуске ввод доступен после настройки. У настроенного пользователя корректный подход сохранён даже при сбое квитанции. Если недоступно обязательное уточнение, бот даёт ссылку и просит ввести число заново. |
