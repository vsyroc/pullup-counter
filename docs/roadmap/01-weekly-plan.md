# Эпик 1. Загрузить программу и выбрать стартовую неделю

- [ ] Загрузить в приложение 30 недель из [проверенной расшифровки](../program.md) вложения заметки `[[План]]`. В каждой строке сохранить номер недели и цели пяти подходов по порядку. Дневниковые записи в заметке описывают фактические тренировки и могут отличаться от целей.
- [ ] Проверить при загрузке, что присутствуют все недели с 1 по 30, номера уникальны, в каждой строке пять целей и их сумма совпадает со столбцом «Всего».
- [ ] Получать обновления Telegram Bot API через long polling (`getUpdates`). По первой команде `/start` в личном чате сохранить `chat_id` для ответов и напоминаний и спросить, с какой недели (1–30) и дня (1–7) начать. Показать пять целей выбранного этапа и сохранить выбор. Если введён номер вне диапазона, предложить выбрать снова. При повторном `/start` показать текущий план и прогресс.

- [ ] Открыть регистрацию для любого пользователя Telegram. Связывать дневник и расписание с Telegram ID пользователя. При записи в группе определять владельца по автору сообщения. Для планов и напоминаний использовать личный chat_id, сохранённый при /start. Запросить фиксированное смещение UTC (например, UTC+5) и дать менять его вручную.

- [ ] Начинать личную историю с регистрации в Telegram. Из Obsidian брать только таблицу целей. При выборе дня 2–7 предыдущие даты оставить без записей и отметок о пропуске.

- [ ] Считать местную дату завершения настройки выбранным днём программы и сразу показать его план, даже при вечерней регистрации. Например, при старте в 20:00 с пятого дня недели 9 первое число откроет сегодняшнюю тренировку, а завтра наступит шестой день.

- [ ] Если автор группового `/set` ещё не прошёл настройку, сохранить введённые значения за его Telegram ID и дать в группе ссылку на личный чат с ботом. После выбора недели, дня и UTC-смещения показать сохранённый ввод автору и предложить записать его с учётом выбранных целей. Повторная отправка команды не требуется.

**Готово, когда** пользователь выбирает неделю 9 и получает первым дневным планом 12, 8, 7, 7, 6 (всего 40). После перезапуска выбор сохраняется, история предыдущих восьми недель остаётся пустой.
